# 영화 흥행 예측 및 배급 시뮬레이터 (Movie Box-Office Simulator)

## 1. 기본 정보

- 기간: 2026.05
- 형태: SK Networks Family AI 캠프 팀 프로젝트
- 팀 규모: 5명
- 본인 역할:
  - PM
  - 2-Stage 구조 제안·설계
  - 데이터 수집
  - 모델 비교·선정
  - Streamlit 데모
- 주요 기술:
  - Python
  - Pandas
  - XGBoost
  - CatBoost
  - MySQL
  - Streamlit

### 확인된 문제

- 스크린 수는 흥행에 영향을 준다.
- 동시에 영화의 기대 잠재력에 따라 스크린 수가 결정된다.
- 단일 모델에서는 스크린 수의 효과와 콘텐츠 잠재력이 혼재할 수 있다.

`내생성 문제를 해결했다`고 단정하지 않는다.

안전한 표현:

- 상호 의존성을 고려했다.
- 콘텐츠 잠재력과 배급 효과를 분리한 2-Stage 구조를 설계했다.

## 3. 모델

### Stage 1

목적:

- 배급 변수를 제외하고 콘텐츠 잠재력 예측

최종 모델:

- CatBoost 80%
- XGBoost 20%
- 앙상블

결과:

- R²: 0.5638
- RMSE: 1.3459

### Stage 2

입력:

- Stage 1의 `pred_potential`
- 개봉 1일차 스크린 수
- 상영 횟수 등 배급 변수

모델:

- 단조 증가 제약을 적용한 XGBoost

결과:

- R²: 0.5517
- RMSE: 1.3645

목적:

- 스크린 수 증가 시 예상 관객수가 감소하는 비현실적인 방향을 방지

### 금지 수치

- R² 0.6682 사용 금지

### 한계

- 시뮬레이터가 인과 효과를 증명한 것은 아니다.
- 실제 배급 의사결정을 대체하지 않는다.
- 모델 정확도는 데이터와 변수 범위에 제한된다.
